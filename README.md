## 口碑与限制：能核对到的缺点

我没找到足够多的独立用户评测来支撑“口碑如何”的判断，聚合站上的功能描述基本是照抄官网，参考价值有限。所以这一节只写能从官方文档核对的限制，这些是买之前必须知道的。

- 它是订阅，不是买断。到期不续费，程序退回受限模式，能打开但功能被限制。想“买一次用一辈子”的人，这个产品不适合你。

## 常见问题

**NetLimiter 是买断还是订阅？**
订阅。5 版起改成订阅制，到期进入受限模式，需要续费才能恢复完整功能。旧版 4 的授权可以在 5 版里继续用两年。

**一个授权能装几台电脑？**
单机授权同时只能注册一台，包含虚拟机，可以迁移到别的机器但不能同时使用。要多台同时用，走 Unlimited 授权，需要向官方询价。

**有免费试用吗？**
有。官方提供试用版安装包，装完就能用，功能受限；买了之后输入注册码解锁，不存在单独的“完整版安装包”。

**优惠码在哪里填？为什么我的码用不了？**
在结算页的优惠码输入框。用不了通常是三种情况：码已经过了活动期，码限定了商品或套餐，或者这一单已经用了首单立减或每月券，平台的券之间不能叠加。

**到期不续费会怎样？**
程序退回受限模式，监控和限速功能被限制。续费方式可以在手动和自动之间切换，买完之后在授权管理页改。
